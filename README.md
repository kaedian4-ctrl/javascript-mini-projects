# JavaScript Mini Projects

A collection of small browser projects built with HTML, CSS, and vanilla JavaScript. Open a project's HTML file in a browser to try it; no build tools or dependencies are needed.

## Projects

- **Click Counter** — Increase or decrease a counter and reset it to zero.
- **Number Guesser** — Guess a number from 1 to 50 in seven attempts.
- **Password Strength Checker** — Check a password against character and length requirements.
- **Rock Paper Scissors** — Play against the computer and keep score.

## Run a project

| Project | HTML file |
| --- | --- |
| Click Counter | `ClickCounter/CCindex.html` |
| Number Guesser | `NumberGuesser/NGindex.html` |
| Password Strength Checker | `PasswordStrengthChecker/PSindex.html` |
| Rock Paper Scissors | `RockPaperScissors/RPSindex.html` |
